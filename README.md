# How to use/install app: 

**Projectoverzicht**: 

Dit project is een Flask web application ontwikkeld voor het project van de vakken [Algoritmen en datastructuren] en [Databasesystemen].
De applicatie laat gebruikers toe in te loggen als coach of speler en heeft dan heel wat functionaliteiten (lessen evalueren, groepslessen of individuele lessen inplannen, speler details bekijken,…)

- Vereisten: 
Voor het lokaal draaien van deze applicatie zijn de volgende zaken nodig:
  - Python 3.10 or higher
  - pip
  - Supabase account

- Installatie:
Voer de onderstaande commando’s uit in een terminal (Command Prompt, PowerShell of Terminal).

1. Clone de repository
```bash
git clone https://github.com/A-D-DBS-application/web-application-2025-group-15.git
cd web-application-2025-group-15

2. Maak een virtuele omgeving aan en activeer deze
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

3. Installeer de vereiste dependencies
pip install -r requirements.txt


4. Start de applicatie met volgend commando

```bash
flask run
```

De applicatie is daarna bereikbaar via:
http://127.0.0.1:5000
